### About this repository
This repository documents my first steps in cloud computing with **Amazon Web Services (AWS)**. As a cybersecurity student aiming for a Blue Team / SOC career, I'm building a solid foundation in cloud concepts, since most modern infrastructure (and most modern attacks) happen there.

### 🧠 What I learned

**Cloud computing fundamentals**
- On-demand delivery of IT resources over the internet with pay-as-you-go pricing.
- Key benefits: trading upfront expense for variable expense, economies of scale, elasticity, speed and agility, and global reach in minutes.
- Service models: IaaS, PaaS and SaaS.

**AWS global infrastructure**
- Regions, Availability Zones and Edge Locations.
- Why multi-AZ designs matter for reliability.

**Security and the Shared Responsibility Model** *(my main area of interest)*
- **Security *of* the cloud** (AWS) vs **Security *in* the cloud** (customer).
- **IAM**: least privilege, default deny, MFA, users, groups, roles and JSON policies.
- **Detection and response**: GuardDuty, Inspector, Detective, Security Hub, CloudTrail.
- **DDoS and web protection**: AWS Shield, AWS WAF, Elastic Load Balancing.
- **Data protection**: encryption, AWS KMS, Macie, ACM.
- **Compliance and governance**: AWS Artifact, Config, Audit Manager, Organizations (SCPs), Control Tower.

**Architecture and operations**
- AWS Well-Architected Framework pillars.
- Monitoring with CloudWatch and Trusted Advisor.
- Pricing models and cost tools.

**Other areas explored**
- Serverless with AWS Lambda.
- Infrastructure as Code (CloudFormation, CDK).
- The 7 Rs of cloud migration.
- Introduction to AI/ML and generative AI (SageMaker, Bedrock, Amazon Q).

### 🔭 Why this matters for Blue Team work
Understanding how cloud environments are built, logged and governed is essential for a SOC analyst.

### 🧠 Lo que aprendí

**Fundamentos de la computación en la nube**
- Entrega de recursos de TI bajo demanda con pago por uso.
- Beneficios: gastos variables, economías de escala, elasticidad, velocidad y alcance global.
- Modelos de servicio: IaaS, PaaS y SaaS.

**Infraestructura global de AWS**
- Regiones, Zonas de Disponibilidad y Ubicaciones Periféricas.
- Importancia de los diseños multi-AZ.

**Seguridad y Modelo de Responsabilidad Compartida** *(mi área de mayor interés)*
- **Seguridad *de* la nube** (AWS) vs **Seguridad *en* la nube** (cliente).
- **IAM**: mínimo privilegio, denegación por defecto, MFA, usuarios, grupos, roles y políticas JSON.
- **Detección y respuesta**: GuardDuty, Inspector, Detective, Security Hub, CloudTrail.
- **Protección DDoS y web**: AWS Shield, AWS WAF, Elastic Load Balancing.
- **Protección de datos**: cifrado, AWS KMS, Macie, ACM.
- **Cumplimiento y gobernanza**: AWS Artifact, Config, Audit Manager, Organizations (SCP), Control Tower.

**Arquitectura y operaciones**
- Pilares del AWS Well-Architected Framework.
- Monitoreo con CloudWatch y Trusted Advisor.
- Modelos de precios y herramientas de costos.

**Otras áreas exploradas**
- Computación sin servidor con AWS Lambda.
- Infraestructura como Código (CloudFormation, CDK).
- Las 7 R de la migración a la nube.
- Introducción a IA/ML e IA generativa (SageMaker, Bedrock, Amazon Q).

### 🔭 Por qué esto importa para Blue Team
Entender cómo se construyen, registran y gobiernan los entornos en la nube es esencial para un analista SOC.
